<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local stdin → client input path | raw bytes (incl. CSI sequences) drive scrollback-mode transitions; must not swallow user keystrokes |
| server scrollback channel → client view buffer | ScrollbackPage content rendered to the local terminal; page from a stale/in-flight request must be dropped when in Live mode |
| previous connection channel state → reattach | channel state must NOT be replayed; the channel is re-opened fresh; view starts Live |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-11 | Tampering / availability | CSI sequence split across stdin reads (Pitfall 6) | mitigate | rolling 8-byte accumulator matches the 6-byte sequences across read boundaries; stateful prefix match, not per-read `windows()` |
| T-22-12 | Denial of service | server pump stall from suspended display | mitigate | datagrams are suspended for DISPLAY only; epoch acks continue while Active so the server pump never stalls |
| T-22-13 | Tampering | replaying channel state on reattach (M-5/MUX-05) | mitigate | reattach re-opens the Scrollback channel fresh with a new even id; no byte-replay; server SessionSlot scrollback persists; view starts Live |
| T-22-14 | Denial of service | unbounded buffering of in-flight pages after snap-back | mitigate | page_rx delivery uses `try_send`/drop-on-Full; pages received while Live are dropped (RESEARCH Open Question 3) |
| T-22-15 | Repudiation/UX | keystroke swallowed during snap-back | mitigate | LOCKED behaviour: the triggering keystroke is forwarded to the shell as PtyData while switching to Live |
| T-22-SC | Tampering | npm/pip/cargo installs | accept | no new packages (RESEARCH audit N/A); no install tasks |
