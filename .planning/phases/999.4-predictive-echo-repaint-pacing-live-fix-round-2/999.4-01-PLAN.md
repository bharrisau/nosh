<objective>
Implement D-01: replace the single-datagram-per-16ms-tick state-diff send with a bounded
burst, so a full-screen repaint (vim startup, multi-line paste) lands in ~1 RTT instead of
dribbling over many ticks × RTT.

Purpose: the only limiter on repaint speed is the one-datagram-per-tick policy (no ack-gating,
no QUIC flow-control ceiling — datagram send buffer is 1 MiB). Bursting the full deferred diff
per tick, bounded by the Layer-1 queue space, drains a large repaint in one tick when the path
allows.
Output: both session pumps in `server.rs` burst multiple MTU-capped datagrams per diff tick,
bounded congestion-transparently via `datagram_send_buffer_space()` (or a fixed count-cap
fallback).
</objective>
