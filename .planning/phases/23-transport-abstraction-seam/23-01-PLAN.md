<objective>
Create the transport abstraction seam in `nosh-proto`: the three object-safe traits (`NoshTransport`, `NoshSendStream`, `NoshRecvStream`), the `SendDatagramError` enum, and the `write_message_ns` / `read_message_ns` codec helpers that work on trait objects. This is the dependency-zero foundation that the server refactor (Plan 02) and Phase 24 (WebTransport) both build on.

Purpose: WT-01 / D-01 — a thin I/O boundary that lets the session pump run over native QUIC or WebTransport with no behavioural change. This plan adds the contracts only; it wires nothing and changes no existing call site.
Output: `crates/nosh-proto/src/transport_trait.rs` (new), `lib.rs` re-exports, `async-trait` + `anyhow` added to `nosh-proto`.
