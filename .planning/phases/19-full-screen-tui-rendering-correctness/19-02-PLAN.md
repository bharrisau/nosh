<objective>
Make character width accurate: add a `wide: bool` continuation marker to `Cell`, drive cursor advancement from `UnicodeWidthChar::width()` in `print_char`, and keep server diff-encoding and client rendering consistent so CJK wide chars and zero-width marks do not cause column drift.

Purpose: `print_char` currently always advances the cursor by 1, so CJK text and emoji drift columns and garble full-screen layouts (TUI-03). The continuation marker (D-19-06) must be an explicit cell, not a literal space, and server/client must agree on its wire treatment.
Output: `unicode-width` added to nosh-server, `Cell.wide` field, width-aware `print_char`, diff-encoder skip of continuation cells, client `emit_diff` skip, and unit tests for `\u{4e2d}` and a ZWJ emoji.
</objective>
