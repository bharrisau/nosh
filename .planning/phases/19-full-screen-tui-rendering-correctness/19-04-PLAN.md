<objective>
Propagate the server's alt-screen state to the client and suppress the speculative predictor while the alternate screen is active (TUI-05): add `alt_screen: bool` to `StateDiff`, set it in `build_state_diff`, and on the entry transition flush predictions with `predictor.reset()`.

Purpose: The speculative local-echo predictor renders overlay cells where the user typed. Inside vim/htop (cursor-addressing apps), typed characters are not echoed in the expected columns, so overlays appear as garbage. `EchoState.alt_screen` is the server's source of truth but is not currently conveyed to the client. Adding it to `StateDiff` (Option A — lower latency, the datagram already carries the snapshot) lets the client suppress on entry.
Output: `alt_screen` on `StateDiff`, server-side wiring, the client `was_alt_screen` transition hook, and the documented postcard wire-format breaking change.
</objective>
