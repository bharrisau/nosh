      bytes to exhaust the 256 KiB credit window before the consumer drains), drive PTY input on stream 0

      shell; use a generous margin only if the harness is noisy, but the assertion threshold is 5 ms per
      SC#3). This proves no HOL blocking between channels.
    - `channel_flow_control_backpressure` (MUX-03): confirm the sender pauses at the credit window and
      resumes only after ChannelCredit is granted — assert forward progress resumes (no deadlock) once the
      consumer drains and credit flows back.
    - `channel_lifecycle_clean` (SC#4 / MUX-04): half-close the channel (finish the send side), confirm the
      peer sees EOF and full-close releases the channel (a subsequent ChannelClose for the same id is a
      no-op); send a ChannelAccept for an id that was never opened and assert the session survives (no
      panic, shell still responds).
    Guard every test on have_sh(). Australian English comments. Never Debug a frame in assertions —
    compare structurally.
