<objective>
Add the server side of the channel-mux layer: control-stream dispatch for the new mux Message
variants, a secondary `accept_bi` arm that binds incoming data streams to channels by their
varint channel-id prefix, a per-channel `tokio::spawn` task with a 256 KiB byte-credit window,
and clean lifecycle teardown. The accept loop and all channel I/O live strictly after
authentication and never block the session pump.

Purpose: Deliver MUX-01 (control-first OPEN/ACCEPT/REJECT, opaque REJECT), MUX-02 (concurrent
per-stream channels with no HOL blocking), MUX-03 (per-channel credit flow control), and the
server half of MUX-04 (clean lifecycle, no-panic on unknown ids, parity enforcement).
Output: `crates/nosh-server/src/channel.rs` (new), extended `run_session`/`run_reattach_session`
select! loops, and channel-map lifecycle.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → server control stream | Untrusted ChannelOpen/Credit/Close frames cross here after auth |
| client → server secondary bidi stream | Untrusted channel-id varint prefix + channel payload |
| pre-auth → post-auth | The accept_bi arm must live only on the post-auth side of the AuthLimits permit |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-03 | Elevation of Privilege | secondary accept_bi loop | mitigate | accept_bi arm exists only inside run_session/run_reattach_session, after drop(permit); never in run_accept_loop — verified by grep gate (Pitfall 2) |
| T-21-04 | Denial of Service | unbounded channel opens | mitigate | MAX_OPEN_CHANNELS cap (64); ChannelOpen past the cap is REJECTed |
| T-21-05 | Denial of Service | slow channel consumer | mitigate | 256 KiB per-channel byte-credit window; sender pauses at 0 credit, never blocks the session pump; channel I/O is in a spawned task (Pitfall 3, MUX-03) |
| T-21-06 | Tampering / Crash | malformed channel-id varint | mitigate | read_varint_u32 returns Err on truncated/oversized varint; stream dropped, not panicked (V5) |
| T-21-07 | Crash | ChannelAccept/Reject/Credit/Close for unknown id | mitigate | unknown-id handlers log + continue, never unwrap/panic (Pitfall 5, MUX-04) |
| T-21-08 | Elevation of Privilege | PortForward/AgentForward accepted early | mitigate | both channel types unconditionally REJECTed by v1.3 peers; SSH_AUTH_SOCK never reachable (FWD-02 deferred) |
| T-21-09 | Information disclosure | REJECT reason oracle | mitigate | ChannelReject carries only channel_id (enforced by the wire type in plan 21-01); identical REJECT for unknown-type, duplicate, parity, and at-cap cases |
</threat_model>
