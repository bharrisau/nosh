<objective>
Append the five channel-multiplexing control variants and the `ChannelType` enum to the
`Message` wire type, and land the `message_discriminant_order_is_stable` test as the FIRST
commit of Phase 21. This is the gating commit: postcard encodes enum variants by 0-based
source-order position, so any insertion before `TerminalControl` silently corrupts the wire
format. The test pins every discriminant byte (old and new) so reordering fails loudly.

Purpose: Establish the stable wire vocabulary every other plan in this phase depends on
(MUX-06). Nothing else can be built until these variants exist with pinned discriminants.
Output: New `Message` variants (discriminants 10–14), `ChannelType` enum, and a byte-level
discriminant-stability test.
</objective>
