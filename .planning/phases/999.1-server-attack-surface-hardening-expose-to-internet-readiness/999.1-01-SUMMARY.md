# Phase 999.1 Plan 01: Fuzz Harness Scaffold + codec_decode Target Summary

cargo-fuzz crate scaffolded with workspace isolation, all six `[[bin]]` targets declared, and the `codec_decode` target proven via 100,000 libFuzzer iterations with no crash on nightly.

## What Was Built

**Task 1 — fuzz/ crate scaffold:**
- Root `Cargo.toml` gains `exclude = ["fuzz"]` under `[workspace]`, keeping `cargo test/build --workspace` away from the `#[no_main]` fuzz binaries.
- `fuzz/Cargo.toml` written with name `nosh-fuzz`, its own `[workspace]` block, `cargo-fuzz = true` metadata, and all required dependencies: `libfuzzer-sys`, `nosh-proto` + `nosh-server` path deps, `arbitrary`, `quinn-proto`, `quinn`, `rustls`, `bytes`, `tokio`, `rcgen`.
- All six `[[bin]]` entries declared: `codec_decode` (real), `read_message`, `decode_datagram`, `decode_epoch_ack`, `osc_accumulation`, `quic_packet` (five minimal stubs for wave-2 plans to overwrite).
- `fuzz/.gitignore` patched: `corpus/` un-ignored (seeds committed), `artifacts/` kept ignored.
- `fuzz/Cargo.lock` generated and committed for reproducible fuzz dep resolution.

**Task 2 — codec_decode target + seed corpus:**
- `fuzz/fuzz_targets/codec_decode.rs` calls `nosh_proto::codec::decode(data)` and discards the result — no `.unwrap()`, so only panics fail the fuzzer.
- Seed corpus generated from five valid postcard bodies: `SessionClose { exit_code: 0 }`, `Resize { 80×24 }`, `PtyData { [0x03] }`, `SessionOpened { token: [0xAB; 16] }`, and an empty file (exercises `DeserializeUnexpectedEnd`).
- `cargo +nightly fuzz run codec_decode -- -runs=100000 -max_total_time=60` completed in 1 second at ~100,000 exec/s with **no crash artifact** — harness proven.
- Full 234-entry minimised corpus committed for reproducible starting coverage on future runs.
