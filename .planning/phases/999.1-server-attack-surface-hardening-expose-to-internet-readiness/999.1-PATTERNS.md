### `fuzz/fuzz_targets/codec_decode.rs` (fuzz target, request-response)

**Analog:** `crates/nosh-proto/src/codec.rs`

**Target function — exact signature** (lines 51–53):
```rust
/// Decode a [`Message`] from a frame body (the postcard-serialized bytes,
/// without the length prefix).
pub fn decode(body: &[u8]) -> Result<Message, ProtoError>
```

Note: `decode` takes the postcard body WITHOUT the 4-byte length prefix. The length prefix is consumed by `read_message`; `decode` gets only the body. This is confirmed by the unit test at line 91: `let body = &frame[4..]; let decoded = decode(body)`.

**Invariant confirmed by existing tests** (lines 84–94): arbitrary input must return `Ok` or `Err(ProtoError)`, never panic. The existing unit tests already validate round-trip; the fuzz target extends this to arbitrary byte sequences.

**Fuzz target shape to copy:**

```rust
use libfuzzer_sys::fuzz_target;

fuzz_target!(|data: &[u8]| {
    // codec::decode takes the postcard body (no length prefix).
    // Invariant: arbitrary input → Ok or Err(ProtoError), NEVER panic.
    let _ = nosh_proto::codec::decode(data);
});
```

**Seed corpus construction** (from unit test at lines 84–94 and 107–133):

### `fuzz/fuzz_targets/read_message.rs` (fuzz target, request-response)

**Analog:** `crates/nosh-proto/src/codec.rs`

**Target function — exact signature** (lines 67–77):
```rust
pub async fn read_message<R: AsyncRead + Unpin>(r: &mut R) -> Result<Message, ProtoError>
```

**Framing protocol** (lines 68–76): reads a 4-byte big-endian `u32` length prefix, then reads exactly `len` bytes as the postcard body. The guard at line 71–73 fires BEFORE any allocation:
```rust
let len = u32::from_be_bytes(len_buf) as usize;
if len > MAX_FRAME_LEN {
    return Err(ProtoError::FrameTooLarge(len));
}
```
`MAX_FRAME_LEN = 16 * 1024 * 1024` (line 14). The allocation `vec![0u8; len]` at line 74 is thus bounded at 16 MiB. The fuzzer must exercise: huge `len` (> 16 MiB), zero `len`, truncated body (shorter than `len` declares), and valid frames.

**Async bridge pattern** (from unit test at lines 107–133 — note `std::io::Cursor` is used directly in the async test):
```rust
#![no_main]
use libfuzzer_sys::fuzz_target;
use std::sync::OnceLock;
use tokio::runtime::Runtime;

fuzz_target!(|data: &[u8]| {
    // OnceLock so we construct the runtime once per fuzz process, not per iteration.
    static RT: OnceLock<Runtime> = OnceLock::new();
    let rt = RT.get_or_init(|| {
        tokio::runtime::Builder::new_current_thread()
            .build()
            .unwrap()
    });
    rt.block_on(async {
        // std::io::Cursor<&[u8]> implements AsyncRead via tokio::io compat.
        let mut cursor = tokio::io::BufReader::new(std::io::Cursor::new(data));
        // Invariant: MAX_FRAME_LEN guard fires before allocation; arbitrary input
        // must return Ok or Err(ProtoError::FrameTooLarge/Io/Postcard), never OOM.
        let _ = nosh_proto::codec::read_message(&mut cursor).await;
    });
});
```

**Seed corpus:** 4-byte big-endian length prefix + matching postcard body. Include: (a) valid round-trip frame for `SessionClose`, (b) length `0x00_00_00_00` + no body, (c) length `0xFF_FF_FF_FF` + 0-byte body (triggers `FrameTooLarge` without allocating), (d) length `0x00_00_00_05` + 3-byte truncated body (triggers `Io(UnexpectedEof)`).

### `fuzz/fuzz_targets/decode_datagram.rs` (fuzz target, request-response)

**Analog:** `crates/nosh-proto/src/datagram.rs`

**Target function — exact signature** (lines 430–447):
```rust
pub fn decode_datagram(bytes: &[u8]) -> Result<StateDiff, ProtoError>
```

**Tag byte protocol** (lines 431–446):
- Byte 0 must be `TAG_STATE_DIFF = 0x01`. Any other value → `Err(ProtoError::Postcard(DeserializeBadEncoding))`.
- After tag check, `postcard::from_bytes(body)` decodes `StateDiff`.
- DoS guard (T-11-02, lines 441–445): if `diff.runs.len() > MAX_RUNS` (4096), returns `Err`.
- Empty input → `Err(DeserializeUnexpectedEnd)` (no tag byte present).

**Existing negative tests as seed corpus sources** (lines 636–679): empty bytes, unknown tag `0xFF`, tag-only (no body), bad postcard body `[TAG_STATE_DIFF, 0xFF]`, and a valid round-trip via `tag_encode`.

**Fuzz target shape:**
```rust
#![no_main]
use libfuzzer_sys::fuzz_target;

fuzz_target!(|data: &[u8]| {
    // decode_datagram checks: (1) non-empty, (2) tag==0x01, (3) valid postcard body,
    // (4) runs.len() <= MAX_RUNS. Invariant: any input → Ok or Err, never panic.
    let _ = nosh_proto::datagram::decode_datagram(data);
});
```

**Seed corpus:** `[0x01]` + valid postcard `StateDiff` body (use `postcard::to_allocvec` on an empty-runs diff), `[0x02, ...]` (wrong tag), `[]` (empty), `[0x01, 0xFF, ...]` (truncated/corrupt body), and a diff with exactly `MAX_RUNS` (4096) runs to probe the boundary.

### `fuzz/fuzz_targets/decode_epoch_ack.rs` (fuzz target, request-response)

**Target function — exact signature** (lines 183–192):

```rust
pub fn decode_epoch_ack(bytes: &[u8]) -> Result<u64, ProtoError>
```

### `fuzz/fuzz_targets/osc_accumulation.rs` (fuzz target, event-driven)

**Analog:** `crates/nosh-server/src/terminal.rs`

**Target method — confirmed public signature** (lines 222–226):
```rust
pub fn advance(&mut self, bytes: &[u8])
```
This is `pub` and takes `&[u8]`. It is the correct fuzz entry point.

**OSC cap constants — confirmed values** (lines 56–63):
```rust
pub const OSC_52_MAX_BYTES: usize = 65_536;
pub const MAX_TITLE_BYTES: usize = 1_024;
```

**OSC dispatch logic** (lines 682–729): `osc_dispatch` is called by `vte::Parser` during `advance`. The title cap check (lines 691–694) discards titles > `MAX_TITLE_BYTES` BEFORE storing. The OSC 52 cap (line 721) truncates data to `OSC_52_MAX_BYTES` before storing. Both caps are applied defensively before any `Vec` or `String` allocation that would persist.

**Public read API for cap assertions** (lines 374–401):
```rust
pub fn osc52_pending(&self) -> Option<(&[u8], &[u8])>
pub fn title(&self) -> Option<&str>
```

**Constructor** (lines 192–206):
```rust
pub fn new(cols: u16, rows: u16) -> Self
```

**Fuzz target shape:**
```rust
#![no_main]
use libfuzzer_sys::fuzz_target;
use nosh_server::terminal::{TerminalState, OSC_52_MAX_BYTES, MAX_TITLE_BYTES};

fuzz_target!(|data: &[u8]| {
    let mut state = TerminalState::new(80, 24);
    // Invariant: arbitrary VT bytes → OSC caps hold, no panic, no unbounded alloc.
    state.advance(data);
    // Assert OSC 52 cap: stored payload must not exceed OSC_52_MAX_BYTES.
    if let Some((_sel, payload)) = state.osc52_pending() {
        assert!(
            payload.len() <= OSC_52_MAX_BYTES,
            "OSC 52 exceeded cap: {} bytes", payload.len()
        );
    }
    // Assert title cap: stored title must not exceed MAX_TITLE_BYTES.
    if let Some(title) = state.title() {
        assert!(
            title.len() <= MAX_TITLE_BYTES,
            "title exceeded cap: {} bytes", title.len()
        );
    }
});
```

**Seed corpus:** `\x1b]2;My Title\x07` (normal title), `\x1b]52;c;SGVsbG8=\x07` (normal OSC 52), `\x1b]2;` + 2000-byte title + `\x07` (title over cap — should be discarded, not stored), `\x1b]52;c;` + 70000-byte payload + `\x07` (OSC 52 over cap — should be truncated), `\x1b]0;` (incomplete OSC), mixed: newlines + CSI sequences + OSC sequences.

### `fuzz/fuzz_targets/quic_packet.rs` (fuzz target, event-driven)

**Analog (partial):** `crates/nosh-client/tests/common/mod.rs` + `crates/nosh-server/src/server.rs`

The integration test common module (`common/mod.rs` lines 107–120) shows the full key-chain setup for a real server. The QUIC packet fuzzer uses a STRIPPED-DOWN version — an ephemeral self-signed cert with no client auth — because:
1. `build_server_config` (server.rs lines 60–101) requires real key files on disk. Manageable with `tempfile` but adds complexity.
2. The fuzzer goal is to test `EndpointConfig` + `migration(true)` misuse, NOT the TLS auth chain.
3. Research recommendation: use independent minimal rcgen self-signed cert + no-client-auth `ServerConfig`.

**Server endpoint configuration pattern to mirror** (server.rs lines 80–98):
```rust
// The real server wires rustls → quinn like this:
let quic_crypto =
    QuicServerConfig::try_from(rustls_cfg).context("convert rustls server config to QUIC")?;
let mut server_config = quinn::ServerConfig::with_crypto(Arc::new(quic_crypto));
server_config.transport_config(Arc::new(nosh_proto::transport_config(false)));
server_config.migration(true);  // MUST mirror this; it's what we're testing
```

**The `migration(true)` call is explicitly the misuse we are testing.** The fuzzer must call `migration(true)` to mirror production config.

**Fuzz target shape** (using quinn-proto sans-IO `Endpoint::handle`):
```rust
#![no_main]
use std::net::{IpAddr, SocketAddr};
use std::sync::{Arc, Mutex, OnceLock};
use std::time::Instant;

use bytes::BytesMut;
use libfuzzer_sys::fuzz_target;
use quinn_proto::{Endpoint, EndpointConfig, ServerConfig as QpServerConfig};

fn make_minimal_server_config() -> Arc<QpServerConfig> {
    // Ephemeral self-signed cert — no real keys or authorized_keys file needed.
    // rcgen is already a workspace dependency (Cargo.toml line 7: rcgen = "0.14").
    let cert = rcgen::generate_simple_self_signed(vec!["localhost".into()]).unwrap();
    let cert_der = rustls::pki_types::CertificateDer::from(cert.cert.der().to_vec());
    let key_der = rustls::pki_types::PrivateKeyDer::try_from(cert.key_pair.serialize_der()).unwrap();
    let _ = rustls::crypto::ring::default_provider().install_default();
    let rustls_cfg = rustls::ServerConfig::builder()
        .with_no_client_auth()
        .with_single_cert(vec![cert_der], key_der)
        .unwrap();
    let mut rustls_cfg = rustls_cfg;
    rustls_cfg.alpn_protocols = vec![nosh_proto::ALPN.to_vec()];
    let quic_crypto = quinn::crypto::rustls::QuicServerConfig::try_from(rustls_cfg).unwrap();
    let mut server_config = QpServerConfig::with_crypto(Arc::new(quic_crypto));
    // Mirror production migration(true) — this is the config we are validating.
    server_config.migration(true);
    Arc::new(server_config)
}

fn make_server_endpoint() -> Endpoint {
    let endpoint_cfg = Arc::new(EndpointConfig::default());
    let server_cfg = make_minimal_server_config();
    Endpoint::new(
        endpoint_cfg,
        Some(server_cfg),
        false,             // allow_mtud: false for determinism
        Some([0u8; 32]),   // rng_seed: fixed for reproducible crashes
    )
}

fuzz_target!(|data: &[u8]| {
    static ENDPOINT: OnceLock<Mutex<Endpoint>> = OnceLock::new();
    let endpoint = ENDPOINT.get_or_init(|| Mutex::new(make_server_endpoint()));

    let remote: SocketAddr = "127.0.0.1:12345".parse().unwrap();
    let now = Instant::now();
    let mut buf = Vec::new();
    let mut ep = endpoint.lock().unwrap();

    // Feed arbitrary bytes as a raw UDP packet. quinn-proto must not panic.
    // Invariant: no panic, no OOM. UB or panic = upstream quinn bug to report.
    let pkt = BytesMut::from(data);
    let _ = ep.handle(now, remote, None, None, pkt, &mut buf);
});
```

**Key API reference** (from RESEARCH.md Pattern 5):
```rust
pub fn handle(
    &mut self,
    now: Instant,
    remote: SocketAddr,
    local_ip: Option<IpAddr>,
    ecn: Option<EcnCodepoint>,
    data: BytesMut,
    buf: &mut Vec<u8>,
) -> Option<DatagramEvent>
```

**Seed corpus:** A valid QUIC Initial packet header (long header form, version 0x00_00_00_01, random DCID/SCID), an all-zeros packet, a single-byte packet, a packet with invalid QUIC version, a packet that looks like a Retry packet.

## Shared Patterns

### Existing Workspace Dependency Pattern

**Source:** `/home/bharris/github.com/bharrisau/nosh/Cargo.toml` lines 17–31

The fuzz crate's `quinn-proto`, `bytes`, and `tokio` dependencies must use compatible versions with the workspace. The workspace pins `quinn = "0.11.9"` which pulls `quinn-proto = "0.11.14"`. The fuzz crate declares `quinn-proto = "0.11"` directly (not as a workspace dep, since fuzz has its own Cargo.toml outside the workspace). `bytes = "1"` and `tokio = "1"` match the workspace declarations.

`rcgen = "0.14"` is already in the workspace dependencies (line 7) — the fuzz crate can reference the same version without re-pinning.

### `ProtoError` Return Convention

**Source:** `crates/nosh-proto/src/codec.rs` lines 18–34

All decoder fuzz targets call functions that return `Result<_, ProtoError>`. The invariant in every target is:
```rust
let _ = some_decoder(data);  // discard Ok or Err — only panics fail the fuzzer
```
Never `.unwrap()` in a fuzz target body. The `ProtoError` type itself is stable: `Postcard`, `FrameTooLarge`, `Io`, `CapTooSmall`.

### Pre-auth Semaphore Pattern (for D-04 doc)

**Source:** `crates/nosh-server/src/server.rs` lines 35–51 and 133–147

```rust
pub struct AuthLimits {
    pub max_concurrent: usize,   // default: 64
    pub auth_timeout: Duration,  // default: 5s
}

// Accept loop — permit acquisition pattern:
let permit = match permits.clone().try_acquire_owned() {
    Ok(p) => p,
    Err(_) => {
        incoming.refuse();  // refuse at QUIC layer before TLS state allocated
        continue;
    }
};
// Permit is dropped as soon as handshake resolves (line 384: drop(permit)),
// so the cap bounds PRE-AUTH state only.
```

The security doc (D-04) must reason about and cite these exact values and this exact pattern.
