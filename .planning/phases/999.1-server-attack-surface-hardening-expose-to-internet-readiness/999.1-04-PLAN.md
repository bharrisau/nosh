<objective>
Stand up the raw QUIC-packet fuzzer (D-02): fire malformed / oversized / truncated UDP bytes at the server's QUIC ingress via quinn-proto's sans-IO `Endpoint::handle`. The goal is to confirm OUR endpoint/config setup (`EndpointConfig::default()`, the rustls→quinn wiring, `migration(true)`) degrades gracefully — no panic, no OOM, no amplification — on hostile packets, and to document which findings are ours vs quinn-proto's. The `quic_packet` `[[bin]]` already exists in `fuzz/Cargo.toml` (Plan 01); this plan adds only the source file + corpus, so it is file-disjoint from Plan 03 and runs in parallel in wave 2.

Purpose: This is the pre-auth packet-layer attack surface on the public UDP/443 ingress — the deepest input boundary before any TLS state. The in-process sans-IO path is deterministic and reproducible (vs a raw-UDP-to-running-server harness, which RESEARCH rejects as flaky).
Output: `fuzz/fuzz_targets/quic_packet.rs` + seed corpus. (The amplification A1/A2 source-check and ours-vs-quinn write-up live in Plan 05's security doc.)
