# Phase 999.1 Plan 02: cargo-audit CI gate (D-03) Summary

Add a `cargo audit` peer job to `.github/workflows/ci.yml` using `actions-rust-lang/audit@v1`, providing a continuous CVE tripwire for transitive dependencies (quinn, rustls, postcard, ring, etc.) on every push and pull request.

## What Was Built

A new `audit` job was appended to `.github/workflows/ci.yml` as a peer of the existing `linux` and `build-windows` jobs. The job:

- Runs on `ubuntu-latest`
- Has exactly 2 steps: `actions/checkout@v4` + `actions-rust-lang/audit@v1` (prebuilt binary — no `cargo install` step)
- Does NOT include `dtolnay/rust-toolchain` or `Swatinem/rust-cache` (not needed by the prebuilt action)
- Scans `Cargo.lock` against the RustSec advisory DB on every push/PR
- Carries an `ignore: ""` placeholder for documenting accepted advisories (RUSTSEC-YYYY-NNNN) without silently widening scope
