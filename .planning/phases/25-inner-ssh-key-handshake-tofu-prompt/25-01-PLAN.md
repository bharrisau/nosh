<objective>
Lay the wire-format and crypto-helper foundation for the WebTransport inner SSH-key handshake. This plan owns the append-only `Message` variant additions (the FIRST commit, per the WF-1 silent-corruption guard), the canonical transcript-layout constants, the `NoshTransport::export_keying_material` trait method (RFC 9266 channel binding, D-01), and two reusable `nosh-auth` helpers so the server and client inner-auth modules add no new crypto.

Purpose: every downstream plan (server wiring, client wiring, integration tests) depends on these contracts. Defining them first prevents the "scavenger hunt" — the server/client executors receive exact variant shapes, label constants, and helper signatures.
Output: variants 18-21 + stability/fieldless tests; transcript label constants in nosh-proto; `export_keying_material` trait method with a default `Err` impl; `check_authorized_key` and `verify_ed25519_spki` in nosh-auth with public re-exports.
</objective>
