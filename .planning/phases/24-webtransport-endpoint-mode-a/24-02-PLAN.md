<objective>
Make the CLIENT session pump generic over the Phase 23 `NoshTransport` trait, mirroring the Phase 23 server refactor. Phase 23 only genericized the server (`run_session`, `run_reattach_session`, channels); the client still threads concrete `&quinn::Connection`, `&mut quinn::SendStream`, `&mut quinn::RecvStream` through `fresh_session` / `reattach_session` / `run_pump` (main.rs) and the `client.rs` session helpers. A WebTransport client (Plan 04) cannot reach a live shell until this seam exists.

Purpose: This is the hidden prerequisite for WT-03. Without it, Plan 04's WT dialer would have no transport-agnostic pump to feed. This is a pure refactor — identical behaviour, all existing tests green — exactly like Phase 23 on the server side.
Output: A client-side `QuinnTransport` pass-through wrapper plus the client pump retargeted to `&dyn NoshTransport` / `Box<dyn NoshSendStream>` / `Box<dyn NoshRecvStream>`.
</objective>
