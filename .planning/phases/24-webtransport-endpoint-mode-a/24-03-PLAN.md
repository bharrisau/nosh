<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network → wtransport accept loop | Untrusted clients attempt HTTP/3 WebTransport CONNECT upgrades; pre-auth state must be bounded |
| outer TLS (CA cert) → inner auth | The outer CA cert proves server identity (browser/proxy-likeness) but is NOT the end-to-end mutual auth; inner SSH-key auth (Phase 25) is authoritative (D-05) |
| build feature → auth bypass | The test-support auth stub must never reach a release build |
| transport mode → protocol surface | A `--mode webtransport` server must not also serve raw QUIC (WT-05) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-03-S | Spoofing | downgrade to raw QUIC (WT-05) | mitigate | Structural: `--mode webtransport` constructs ONLY a `wtransport::Endpoint<Server>`; the quinn endpoint is never created; non-WT clients fail at the HTTP/3 CONNECT upgrade and never produce an `IncomingSession`. Asserted in SUMMARY + verified by Plan 05's downgrade test |
| T-24-03-E | Elevation of Privilege | test-support auth bypass in release | mitigate | Stub gated `#[cfg(any(test, feature = "test-support"))]`; release `--features webtransport` build rejects any connection lacking inner auth via `transport.close(1, ...)` BEFORE any session work. Verified by a release-build compile check + Plan 05 |
| T-24-03-D | Denial of Service | unbounded pre-auth WT sessions | mitigate | `run_wt_accept_loop` replicates the `Semaphore(max_concurrent)` cap + `auth_timeout` from `run_accept_loop`; over-cap incomings are dropped |
| T-24-03-I | Information Disclosure | outer TLS cert trust | accept | D-05: a terminating/compromised proxy is contained by inner auth (Phase 25); the outer CA cert is intentionally a normal server identity, documented in SEC-01 (Phase 27). The `CLAUDE.md` "never PKI chains for host verification" note applies to native QUIC, NOT this outer layer |
| T-24-03-SC | Tampering | wtransport install | mitigate | Covered by Plan 01 audit (wtransport [OK]); no new packages here unless `rustls-pemfile` is added — if added, verify on crates.io (RustCrypto/rustls org, established) before commit |
</threat_model>
